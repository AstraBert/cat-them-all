📱 How to Install on Android

  1. Click the "Download for Android" button above
  2. You'll be redirected to the Expo build page
  3. Click "Download" to get the APK file
  4. Open the downloaded APK file on your Android device
  5. Allow installation from unknown sources if prompted
  6. Install and start catching cats!

🍎 How to Play on iOS

  1. Download Expo Go from the App Store
  2. Ask the developer to start the development server
  3. Scan the QR code with your iPhone camera
  4. The game will open in Expo Go
  5. Start your cat-catching adventure!
